Module Overview

During the previous modules, we discussed relational databases, entities, attributes, relationships, primary keys, foreign keys, and database design.

Now we will begin communicating directly with a database using Structured Query Language (SQL).

SQL allows developers, database administrators, analysts, and applications to interact with relational databases.

SQL can be used to:

  • Create database structures.
  • Add information to a database.
  • Search and retrieve information.
  • Modify existing information.
  • Delete information.
  • Summarize and analyze large collections of data.
Important: SQL is one of the most important skills you will learn in this course. SQL is used by software developers, data analysts, cybersecurity professionals, system administrators, and database administrators.

Lecture: Introduction to SQL

1. What is SQL?

SQL stands for Structured Query Language. It is a language designed specifically for interacting with relational databases.

Popular relational database systems that use SQL include:

  • PostgreSQL
  • MySQL
  • Microsoft SQL Server
  • Oracle Database
  • SQLite

Although each database platform may contain additional features, the fundamental SQL commands are very similar.

2. Categories of SQL Commands

Category Purpose Examples
DDL Defines database structures CREATE, ALTER, DROP
DML Changes data INSERT, UPDATE, DELETE
DQL Retrieves data SELECT

3. Creating a Table

Before information can be stored, a table must be created. The following example creates a customer table. 

CREATE TABLE customers (
    customer_id SERIAL PRIMARY KEY,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    email VARCHAR(100),
    city VARCHAR(50),
    state CHAR(2)
);

4. Understanding Data Types

Every column in a relational database has a data type. The data type determines what kind of information can be stored.

Data Type Description Example
INTEGER Whole numbers 25
VARCHAR Variable-length text Jeff
DATE Date values 2026-09-28
DECIMAL Numbers containing decimals 19.99
BOOLEAN True/False values TRUE

5. Inserting Data

The INSERT statement adds records to a table. 

INSERT INTO customers
(first_name, last_name, email, city, state)
VALUES
('Alex', 'Morgan', 'alex@example.com', 'Pittsburgh', 'PA');

Multiple records can also be inserted:

INSERT INTO customers
(first_name, last_name, email, city, state)
VALUES
('Sarah', 'Smith', 'sarah@example.com', 'Washington', 'PA'),
('James', 'Wilson', 'james@example.com', 'Pittsburgh', 'PA'),
('Maria', 'Garcia', 'maria@example.com', 'Morgantown', 'WV');

6. SELECT Statements

SELECT retrieves information from a database. 

SELECT * FROM customers;

The asterisk (*) means return every column.

You can also request specific columns:

SELECT first_name, last_name, email
FROM customers;

7. Filtering with WHERE

The WHERE clause limits which records are returned. 

SELECT *
FROM customers
WHERE state = 'PA';

You can also compare numeric values.

SELECT *
FROM products
WHERE price > 20;

8. AND and OR

Multiple conditions can be combined. 

SELECT *
FROM customers
WHERE state = 'PA'
AND city = 'Pittsburgh';

OR allows either condition to be true.

SELECT *
FROM customers
WHERE state = 'PA'
OR state = 'WV';

9. Using LIKE

LIKE searches for patterns inside text. 

SELECT *
FROM customers
WHERE last_name LIKE 'S%';

The percent symbol (%) represents any number of characters. The query above finds last names beginning with S.

10. Using IN

IN is useful when checking several possible values. 

SELECT *
FROM customers
WHERE state IN ('PA', 'WV', 'OH');

11. Using BETWEEN

BETWEEN searches for values within a range. 

SELECT *
FROM products
WHERE price BETWEEN 10 AND 25;

12. Sorting Results

ORDER BY controls the order in which records are displayed. 

SELECT *
FROM customers
ORDER BY last_name ASC;

Descending order:

SELECT *
FROM customers
ORDER BY last_name DESC;

13. Updating Records

UPDATE changes existing information. 

UPDATE customers
SET city = 'Canonsburg'
WHERE customer_id = 1;
Warning: Always be careful when using UPDATE. If you forget the WHERE clause, every record in the table could be modified.

14. Deleting Records

DELETE FROM customers
WHERE customer_id = 1;
Warning: Running DELETE without a WHERE clause can remove every record from the table.

15. Aggregate Functions

Aggregate functions perform calculations using multiple records.

COUNT

SELECT COUNT(*)
FROM customers;

AVERAGE

SELECT AVG(price)
FROM products;

SUM

SELECT SUM(price)
FROM products;

MIN and MAX

SELECT MIN(price), MAX(price)
FROM products;

16. GROUP BY

GROUP BY allows us to organize records into groups before performing calculations. 

SELECT state, COUNT(*)
FROM customers
GROUP BY state;

This query counts how many customers are located in each state.

Module 4 Lab: Building and Querying a Database

Scenario

You have been asked to create a small database for a business that needs to track products and customer orders.

Part 1 – Create the Products Table

CREATE TABLE products (
    product_id SERIAL PRIMARY KEY,
    product_name VARCHAR(100) NOT NULL,
    category VARCHAR(50),
    price DECIMAL(8,2),
    quantity INTEGER
);

Part 2 – Insert Product Data

INSERT INTO products
(product_name, category, price, quantity)
VALUES
('Wireless Mouse', 'Electronics', 24.99, 20),
('Keyboard', 'Electronics', 49.99, 15),
('USB-C Cable', 'Electronics', 12.99, 30),
('Laptop Stand', 'Office', 39.99, 10),
('Notebook', 'Office', 5.99, 50),
('Desk Lamp', 'Office', 29.99, 12),
('Coffee Mug', 'Kitchen', 14.99, 25),
('Water Bottle', 'Kitchen', 19.99, 18);

Part 3 – Run Basic Queries

Display every product:

SELECT *
FROM products;

Display only product names and prices:

SELECT product_name, price
FROM products;

Part 4 – Filtering

Find products costing more than $20:

SELECT *
FROM products
WHERE price > 20;

Find Electronics products:

SELECT *
FROM products
WHERE category = 'Electronics';

Part 5 – Sorting

Display products from most expensive to least expensive:

SELECT *
FROM products
ORDER BY price DESC;

Part 6 – Aggregate Functions

Determine the average product price:

SELECT AVG(price)
FROM products;

Determine the number of products:

SELECT COUNT(*)
FROM products;

Part 7 – Your Queries

Create SQL statements that answer each question:

  1. Which products cost less than $20?
  2. Which products have a quantity greater than 20?
  3. Which products are in the Office category?
  4. What is the most expensive product?
  5. What is the least expensive product?
  6. How many products exist in each category?
  7. What is the total quantity of all products?
